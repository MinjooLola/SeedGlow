---
name: 시트 변경 재실행 안전성
description: 시트 상태가 승인 대기 중 바뀌거나 API 조회 제한이 발생할 때의 변경·검증 원칙
---

사용자가 승인한 시트 변경을 실행하기 전에 현재 상태를 확인한다. 승인된 항목이 이미 목표 상태라면 다시 쓰지 않고 결과를 검증한다. 승인 당시의 예상 변경 건수와 현재 남은 변경 건수가 다르다는 이유만으로 완료된 상태를 실패로 처리하지 않는다.

**Why:** 비공개 후기 공개 승인 뒤 조회한 시트가 이미 모두 공개 상태였던 사례가 있었다. 추가 조회는 API 제한에 걸렸고, 잠시 뒤 현재 상태를 다시 확인해 불필요한 쓰기를 피했다. 상태가 바뀐 원인은 확인하지 못했으므로 추정하지 않는다.

**How to apply:** 승인된 항목만 대상으로 삼아 게시 설정과 게시용 문구 보존을 확인한다. 대기 중 추가된 새 항목까지 승인 범위를 넓히지 않는다. 조회 제한에는 대기 후 제한된 횟수로 재시도하고, 원본이 목표 상태여도 앱 캐시와 실제 표시가 갱신됐는지 별도로 확인한다.
