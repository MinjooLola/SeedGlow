---
name: 공개 홈페이지 콘텐츠 가용성
description: 미리보기와 공개 사이트의 가용성을 별도로 검증해야 하는 이유
---

공개 홈페이지 장애를 확인할 때 정적 화면이 열리는지만 확인하지 말고, 실제 콘텐츠 API의 응답 완료와 각 목록의 표시를 확인한다. 미리보기 정상이나 시트 설정 존재만으로 운영 연결도 정상이라고 결론 내리지 않는다.

**Why:** 공개 사이트의 일반 페이지와 robots.txt는 정상 응답했지만 콘텐츠 요청은 수 분 동안 응답하지 않았고, 같은 시트를 읽는 미리보기는 정상이었던 사례가 있다. 당시 권한 오류 응답은 확인되지 않았으므로 인증 만료라고 단정할 근거도 없었다.

**How to apply:** 운영 문제는 공개 주소에서 제한 시간을 둔 콘텐츠 요청으로 확인한다. 공개 서버의 외부 읽기가 멈추어도 마지막 실제 성공 콘텐츠를 표시하는 것이 사용자가 승인한 복구 방향이다. 복구본 표시와 원본 연결의 정상 갱신은 서로 다른 검증 항목이다.
