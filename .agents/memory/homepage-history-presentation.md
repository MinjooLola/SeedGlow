---
name: 홈페이지 이력 표시
description: 홈페이지 이력 업데이트 시 사용자가 원하는 표시 방식과 수정 범위
---

기존 강의·컨설팅·심사 3개 분류와 대표 소개 문구를 유지하고 추가된 이력만 넣는다. 전체 이력서 형태로 확장하지 않는다.

**Why:** 사용자는 이력서 형태로 변경한 화면보다 기존 분류 방식과 대표 설명이 더 낫다고 명시했다.

**How to apply:** 홈페이지 실적 업데이트에는 기존 목록을 보존하고 새 활동을 해당 분류에 추가한다. 학력·기술·기간 등 전체 이력서 요소를 화면에 확장하는 것은 별도 요청이 있을 때만 한다.
