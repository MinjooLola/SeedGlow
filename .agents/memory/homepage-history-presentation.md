---
name: 홈페이지 이력 표시
description: 홈페이지 이력 업데이트 시 사용자가 원하는 표시 방식과 수정 범위
---

대표 소개 문구를 유지하고 실적의 강의·컨설팅·심사 구분을 보여 준다. 학력·기술 등을 포함한 전체 이력서 형태로 확장하지 않는다.

**Why:** 사용자는 이력서 형태로 변경한 화면보다 기존 분류 방식과 대표 설명이 더 낫다고 명시했다.

**How to apply:** 사용자가 다시 “이력부분은 기존 양식대로”라고 요청했으므로 대표 소개 아래 기존 강의·컨설팅·심사별 목록을 유지한다. 날짜별 이력서 표로 바꾸지 않는다. 시트 원문을 유지하고 그룹 안에서 행 순서를 보존한다. 복합 활동의 그룹별 표시는 허용하되 누적 건수는 원본 행을 한 번씩만 센다.
