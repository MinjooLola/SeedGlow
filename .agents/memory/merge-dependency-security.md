---
name: 병합 후 의존성 보안 검사
description: 정상 실행 중인 앱의 재설치가 패키지 보안 정책에 차단될 때의 대응
---

현재 앱이 실행된다고 해서 잠금 파일의 의존성이 새 설치에서도 허용된다고 가정하지 않는다. 병합 후 설치를 실제로 검증한다.

**Why:** 기존 실행 환경은 정상이어도 깨끗한 설치에서는 오래된 간접 의존성이 보안 정책에 차단된 적이 있다. 깨끗한 설치가 실패하면 기존 모듈도 제거돼 개발 환경 복구가 필요할 수 있다.

**How to apply:** 방화벽을 우회하지 않고 공식 패키지 설치 경로에서 호환되는 최신 수정 버전을 선택한다. 제품 동작을 바꾸는 주요 버전 전환보다 호환 패치를 우선하고, 자동 병합 후 설치·검사·빌드를 다시 실행해 복구를 확인한다.
