---
name: 홈페이지 이력 표시
description: 홈페이지 이력 업데이트 시 사용자가 원하는 표시 방식과 수정 범위
---

대표 소개 문구를 유지하고 실적의 강의·컨설팅·심사 구분을 보여 준다. 학력·기술 등을 포함한 전체 이력서 형태로 확장하지 않는다.

**Why:** 사용자는 이력서 형태로 변경한 화면보다 기존 분류 방식과 대표 설명이 더 낫다고 명시했다.

**How to apply:** 대표 소개 아래 기존 강의·컨설팅·심사별 목록을 유지한다. 날짜별 이력서 표로 바꾸지 않는다. 시트 원문을 유지하고 그룹 안에서 행 순서를 보존한다.

강의·컨설팅·심사의 현재 기준은 운영 시트의 `이력_3열보기` 탭이다. 그 탭의 각 열에 배치된 대로 표시하며 과거 분류나 활동명 추정으로 다른 그룹에 중복 배치하지 않는다. 날짜는 표시하지 않는다.

**Why:** 사용자가 이 탭을 직접 지정해 “참고해서 다시 정리해. 대신 날짜는 넣지마”라고 요청했다. 이전의 복합 활동 중복 표시보다 이 명시적 분류가 우선한다.

**How to apply:** 항목 문구와 각 열 안의 행 순서를 보존하고 뒤에 붙은 날짜 주석만 제외한다. 교과목 이름에 들어간 연도는 항목 이름의 일부이므로 임의로 바꾸지 않는다. 대표 소개와 별도의 팀 수·투자 금액은 변경하지 않는다.
